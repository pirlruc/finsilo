# Security

FinSilo is an Android app. It stores the ledger in SQLCipher and keeps
the screen secure while the lock overlay is up.

## Reporting a vulnerability

Report a vulnerability through GitHub private vulnerability reporting on
this repository. Do not open a public issue for an unfixed security bug.

Include the app version, the Android version, and enough detail to
reproduce the problem. Do not send account exports, API keys, or recovery
codes.

## Supported versions

Security fixes target the current `main` branch. Release signing secrets
must be confirmed before a version tag is published.
