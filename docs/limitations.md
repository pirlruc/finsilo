# Limitations

Authored leftovers that already have an Epic/Task stay in [`docs/issues.yml`](issues.yml).
This file is only for **known limits that are not issues** (product/API/CI facts), plus
the one Phase 7 gate that is wired but not yet green.

| ID | Limitation | How to overcome | Status | Stops being a limitation when |
| --- | --- | --- | --- | --- |
| LIM-COV | `:domain` Kover is **94.6% line / 70.3% branch** vs org **95/95** (`statement_coverage` / `branch_coverage`). Gradle `koverVerify` and the `kover` CI job read those keys fail-closed and will fail until coverage catches up. No lowered-gate deviation is recorded. Tracked as open [GATE-001-T3](issues.yml). | Add domain tests for remaining branches (parsers, ledger/valuator edge paths, enum `when`s). Do not lower the profile or add a fake deviation. | **Open — gate wired, not green** | `./gradlew :domain:koverVerify` is green at the profile 95/95 numbers |
| LIM-SUB | `docs/guardrails` and `.github/scaffold` are **private** submodules. GitHub Actions on this public repo cannot clone them with `GITHUB_TOKEN`. CI therefore reads the committed copy [`config/kotlin.profile.thresholds.yml`](../config/kotlin.profile.thresholds.yml) (pin 1.3.0). When the analog tree is present, `scripts/read_kotlin_threshold.py` requires every key to match. | Make the analog repos public, **or** store an Actions secret (fine-grained PAT, Contents: Read on `pirlruc/guardrails`) and pass `token` + `submodules: recursive` on checkout. Keep the consumer copy in lockstep whenever the submodule pin moves. | **Open — analog clone** | Analog is public, or CI clones the submodule, and jobs read `docs/guardrails/kotlin/profile.thresholds.yml` directly |
| LIM-SG | Semgrep CI uses community `r/kotlin` + `r/generic.secrets` without login. Packs such as `p/kotlin` / `p/security-audit` need a Semgrep account. | `semgrep login` (or a vendored rulepack) in CI; keep `--severity ERROR --error`. | **Open — SAST depth** | Registry packs run in `security.yml` and ERROR findings still fail the job |
| LIM-MI | Kotlin profile has `min_maintainability_index: 40` (KT-CPLX-002). detekt does not emit that metric; cyclomatic max 10 is the enforceable proxy (`scripts/check-detekt-complexity.py`). | Adopt a Kotlin MI tool (or a detekt plugin that reports MI) and fail-closed on `min_maintainability_index`. | **Open — metric gap** | CI reads `min_maintainability_index` from the profile and a measured MI gate is green |
| LIM-SBOM | No CycloneDX/SPDX SBOM (SC-SBOM-001). There is no published APK/AAB/library artifact yet. | When a release artifact exists, generate SBOM (e.g. syft / CycloneDX Gradle) and attach it to the release (SC-SBOM-002). | **Open — no published artifact** | A release asset ships with a retained CycloneDX and/or SPDX SBOM |
| LIM-REL | No cosign signing or SLSA provenance (SC-SIGN-001, SC-PROV-001). Same reason as LIM-SBOM. | Add a tag/release workflow with keyless cosign and `actions/attest-build-provenance`. | **Open — no published artifact** | A signed, attested release is produced from CI |
| LIM-HOOK | KT-SEC-003 asks for secret scanning in CI **and** pre-commit. Only CI (`scripts/run-gitleaks.sh`) is wired. Adding pre-commit would add a Dependabot ecosystem (SC-DEP-001). | Add `.pre-commit-config.yaml` with pinned gitleaks and a `pre-commit` Dependabot updates entry. | **Open — local hook** | `pre-commit run` (or equivalent) runs gitleaks locally and Dependabot covers that ecosystem |
| LIM-EMU | CI runs **Robolectric** Room tests (`:app:testDebugUnitTest`), not an emulator. SQLCipher native is not exercised; tests use in-memory unencrypted Room. `testInstrumentationRunner` remains `AndroidJUnitRunner`. | Add an instrumented emulator/device job; keep a failing SQLCipher/Compose test as the CI signal. | **Open — device CI** | Instrumented tests run on an emulator/device job and a failing SQLCipher/Compose test fails that job |
| LIM-MIN | Release `isMinifyEnabled` is still `false`. | Turn on R8 with a tested ProGuard config and an assembleRelease CI job. | **Open — release hardening** | Release minify is on and `assembleRelease` is green in CI |
| LIM-AV | Alpha Vantage free tier is about 25 calls/day. Many US holdings plus `TIME_SERIES_DAILY` full still exhaust it even with OVERVIEW skipped when a rating is newer than 7 days. | Paid AV tier, fewer US names, or another GET-only US history source that is not unofficial Yahoo. | **Open — API quota** | Quota no longer blocks a normal US book, without unofficial Yahoo |
| LIM-EU | `looksEuropean` only treats `.DE` / `.PA` / `.AS` / `.MI` / `.MC` (plus `PTY*`) as Stooq-first. Tickers like `.L` or `.SW` go AV-first. | Extend the suffix table and add a test per exchange the portfolio actually uses. | **Open — feed routing** | Suffix table covers the exchanges in use, with a test per suffix |
| LIM-NAV | `nav_history` full-rebuilds on ledger/quote change (append only when as-of moves forward). A single new transaction still walks the whole series. | Incremental rebuild (apply only dates ≥ changed tx) without changing TWR split rules. | **Open — performance** | Incremental rebuild lands and existing TWR tests still pass |
| LIM-GH | GitHub issue publish 403s: token is `issues=read`. YAML ids are the source of truth. | PAT/GitHub App with **Issues: Read and write**; then `bash scripts/setup-issue-scaffold.sh` and `issues-sync.sh`. | **Open — token scope** | Labels, milestones, and issues sync from `docs/issues.yml` without 403 |

Do not copy these rows into `docs/issues.yml` unless they become planned work. Do not reopen [FS-DEC-001](issues.yml) for them.
